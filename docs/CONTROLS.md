# Схема управления для TrimUI Brick (Strict Physical Controls)

> [!IMPORTANT]
> **Управление строго кнопочное.** Никаких мышей и виртуальных экранных курсоров.
> - Вкладки игр сверху переключаются плечевыми триггерами **L1 / R1**.
> - Игра **всегда стартует со Слотов** (никакого отдельного экрана Лобби).
> - Перемещение внутри столов — дискретная сетка **D-Pad** с рамкой фокуса.

---

## 1. Глобальные горячие клавиши (работают всегда)

| Кнопка TrimUI Brick | Действие |
| :--- | :--- |
| **L1** | Предыдущая игра (вкладка влево: Покер <- Рулетка <- Блэкджек <- Слоты) |
| **R1** | Следующая игра (вкладка вправо: Слоты -> Блэкджек -> Рулетка -> Покер) |
| **SELECT** | Мгновенный переключатель валюты (₽ <-> $) |
| **START** | Меню настроек (Язык RU/EN, звук, спасение от банкротства) |

---

## 2. Управление в играх

### 2.1. Звездный слот (Стартовый экран)
- **X** или **A** — **SPIN (Крутить)** / Досрочно остановить барабаны.
- **D-Pad Вверх / Вниз** — Изменить ставку (`+100` / `-100`).
- **D-Pad Влево / Вправо** — Изменить ставку крупным шагом (`-1 000` / `+1 000`).
- **Y** — **ALL-IN** (Поставить весь банкролл).

### 2.2. Рулетка долины (Дискретная сетка 0–36)
- **D-Pad (Вверх/Вниз/Влево/Вправо)** — Перемещение золотой рамки фокуса по ячейкам стола (Зеро, числа 1-36, дюжины, Красное/Черное).
- **A** — Положить выбранную фишку на подсвеченную ячейку.
- **B** — Убрать фишку с текущей ячейки (Undo).
- **Y** — Сменить номинал фишки (100 -> 500 -> 2.5K -> 10K -> ALL-IN).
- **X** — **SPIN WHEEL (Запустить шарик)**.

### 2.3. Калико-Джек (Блэкджек)
- **A** — **HIT** (Взять карту).
- **B** — **STAND** (Хватит).
- **Y** — **DOUBLE** (Удвоить ставку).
- **X** — **NEW DEAL** (Новая сдача).
- **D-Pad Вверх / Вниз** — Изменение ставки перед раздачей.

### 2.4. Салунный дро-покер
- **D-Pad Влево / Вправо** — Выбор карты из 5 сдаваемых.
- **A** — Зафиксировать карту (`ДЕРЖАТЬ` / `HOLD`).
- **X** — **DRAW** (Обменять незафиксированные карты).
- **D-Pad Вверх / Вниз** — Изменение ставки.
